# NNN. Decision in one sentence

- **Status:** Accepted | Superseded by NNN
- **Date:** YYYY-MM-DD
- **Sources:** PRs, commits, CHANGELOG versions

## Context

What forced a decision. Measured facts, with where they come from. No production hostnames, IPs or dashboards.

## Decision

What the code does now, and where (module and function names, not line numbers).

## Alternatives

What else was possible and why it lost. Mark an alternative as reconstructed if nothing records it.

## Consequences

What gets easier, what gets harder, what an operator must do.

## Don't

The plausible "cleanups" that would undo this decision, and the tests that guard against them.
