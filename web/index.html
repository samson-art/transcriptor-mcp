Connect in 30 seconds

One hosted endpoint. Sign in through your browser on first use — no API keys, no tokens.

https://gateway.mcpal.io/mcp/transcriptor

Paste this into an MCP client, not a browser. The first connection opens a sign-in page in your browser; approve it once and the client keeps the session. No API keys, no tokens.

What you can ask

Eight read-only tools. Long transcripts return in full, or in cursor-paged parts on request — no text is lost.

Ask for thisTool
“Summarize this video for me”get_transcript
“Give me the subtitles as an SRT file”get_raw_subtitles
“Is there a German track for this video?”get_available_subtitles
“Who published this and how many views?”get_video_info
“Go to the part about pricing”get_video_chapters
“Show me the screen at 4:12”get_video_frame
“Get transcripts for the first 5 videos in this playlist”get_playlist_transcripts

01:30

Widgets

Four tools show an interactive interface in clients that support MCP Apps and the ChatGPT Apps SDK. Other clients get the same data as text and JSON.

These are the real widgets, running live on recorded data — click around: open a search result, load captions, step through frames.

02:00

Platforms

YouTube · Twitter/X · Instagram · TikTok · Twitch · Vimeo · Facebook · Bilibili · VK · Dailymotion · Reddit

Every video tool accepts a link from these 11 platforms; search_videos works with YouTube. The server retrieves only public captions, metadata and single frames — it does not download video or audio files.

02:30

Self-host

The same tools, on your machine. Open source (MIT), no account needed.

docker run --rm -p 4200:4200 artsamsonov/transcriptor-mcp:latest

Then point your client at http://localhost:4200/mcp. See the self-host guide for stdio mode, Whisper fallback, caching and the REST API.
